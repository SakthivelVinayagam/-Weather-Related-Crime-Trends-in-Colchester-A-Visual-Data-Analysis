Weather–Crime Trends Analysis (Colchester, UK)

Overview

This project analysed the relationship between weather conditions and crime patterns in Colchester, UK. The aim was to identify seasonal trends and temporal–spatial crime variations using advanced statistical analysis and visualisation.

Dataset
	•	16,000+ crime reports from Colchester police records.
	•	Daily weather data including temperature, humidity, and precipitation.
	•	Merged datasets to enable temporal and correlation analysis.

Methodology
	•	Data cleaning, merging, and transformation using R.
	•	Time-series analysis with rolling averages and correlation studies.
	•	Built interactive dashboards with plotly and leaflet; created animated visualisations with gganimate.

Technology Stack

R · ggplot2 · plotly · leaflet · dplyr · lubridate

Results
	•	Identified seasonal crime spikes influenced by weather conditions.
	•	Delivered insights for public safety resource allocation.
